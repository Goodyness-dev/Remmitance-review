# Demo script

[Captioned opening preview](demo-opening.webm) shows the first three evidence beats from the running app. The live QoreX approval and release sequence are for the final recording.

- **0:00–0:25** Open on the hold. “This fictional hospital is about to send ₦12.4 million. The beneficiary, amount and reference match. The bank account changed.” Select Compare accounts so the slips separate.
- **0:25–0:45** Trace the difference. Point out when the file was received and why the editor is unknown. Show the disabled release control.
- **0:45–1:35** Request a legitimate replacement, confirm it as the receiving authority and sign in QoreX. Show the Diana transaction result.
- **1:35–2:10** Show the matching file and complete simulated release. Export the restricted evidence and verify the public fingerprint.
- **2:10–2:30** Explain where the comparison would fit in a real hospital's naira payment process. End on the verified testnet record.
